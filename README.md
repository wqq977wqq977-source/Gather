# Gather

把值得关注的资产，放在一起。

Gather 是一款 Android 原生、本地优先的个人资产工具。将银行余额、证券可用现金、A 股 / ETF 和数字货币持仓汇总到一份资产视图，用手绘风格的图表查看当前分布和每日变化。界面目前为中文。

## 下载与安装

**Android 8.0 及以上**：[下载最新 APK](https://github.com/wqq977wqq977-source/Gather/releases/latest)。在 Release 的 Assets 中选择 `.apk`，下载后打开，按系统提示允许该来源安装。

当前版本 **0.7.0**。包含同屏多层桑基图与系统栏显示修正，原名「归拢」。包名与签名保持不变，可覆盖此前同签名试用版；升级前建议导出加密备份。GitHub Release 附带 SHA-256 校验文件。

## 能做什么

- 管理银行、证券、数字资产和其他资金账户，自选账户图标。
- 汇总账户现金与持仓市值，查看每日资产记录、趋势曲线及当前资产环图。
- 同屏展示总资产、类别、账户与持仓的多层桑基图；支持放大、平移、路径选择与金额隐藏。
- 获取 A 股 / ETF 快照及 BTC、ETH、SOL、BNB、XRP、DOGE、USDT、USDC 行情；数字货币数量支持八位小数。
- 以 CNY 或 USD 显示汇总金额，显示参考汇率来源与日期。
- 选择彩铅手帐或蓝墨手帐，跟随系统深浅色，离线字体随应用打包。
- 导出、恢复带密码的 AES-GCM 加密备份；无登录、无云端账本服务。

## 开始使用

1. 添加账户，手动录入现金余额。
2. 在相应账户录入持仓代码、数量和单位成本，等待行情更新；也可以先进入隔离的示例预览。
3. 买卖后自行更新现金、持仓数量及成本，定期在「设置与数据」导出加密备份。

证券账户只填写**可用现金**。例如现金 10,000 元、持仓市值 5,000 元，应分别录入，应用合计为 15,000 元；不要把账户总资产再次填入现金。

## 计算与数据边界

总资产 = 全部账户现金 + 持仓市值。每日资产变化包含资金流入流出和手动调整，**不等于投资收益**。股票涨跌幅使用较昨收变化，数字货币使用 24 小时变化，两者时间口径不同。

账本、录入和历史快照仍以人民币保存；USD 是按当前参考汇率折算的显示值，历史美元曲线也使用该汇率。没有行情时暂按成本估值，断网保留上次报价。历史从首次记录开始，没有记录的日期不会补造。

不连接银行、券商或钱包，不同步成交，不执行交易；手续费、分红、拆并股及已实现收益需自行维护。公共行情可能延迟或不可用。前台周期检查行情；后台任务受 Android 系统调度影响，不保证准点。

## 隐私与备份

账本保存在应用私有目录，禁用系统自动云备份；本机账本未额外加密，也没有应用锁。外部请求用于行情和参考汇率，不上传账户名称、余额或持仓数量。股票行情使用腾讯接口，数字货币使用 CoinGecko，参考汇率使用 Frankfurter；联网会向服务提供方暴露网络请求及所查询的证券/币种。

`.guilong` 备份使用密码派生密钥和 AES-GCM 加密，保留该扩展名以兼容旧备份。schema 3 支持读取旧 schema 1/2；旧版应用不能读取新 schema。界面风格与显示币种偏好不包含在账本备份内。恢复会在确认后替换当前账本；忘记密码无法恢复，卸载或清除数据会删除本机账本。

## 开发与验证

原生 Java / Android Views / Canvas；最低 API 26，compile/target API 35；Android Gradle Plugin 8.9.2、Gradle 8.11.1、JDK 17。

```bash
git clone https://github.com/wqq977wqq977-source/Gather.git
cd Gather
# 配置 Android SDK 35 / Build Tools 35.0.0 和 JDK 17
./gradlew :app:assembleDebug
```

本地离线构建及领域测试见 [构建说明](docs/BUILD.md)。标准 Gradle 构建路径尚未在维护者本机验证。发行包使用本地离线构建器及私有签名身份；签名文件不随源码发布，其他人构建的 APK 无法覆盖官方同包名安装。

0.6 功能此前已在 Android 15 手机模拟器验证；本次发布的实际检查见 [发布验证](docs/releases/0.7.0.md)。模拟器检查不能替代真机、TalkBack、厂商后台策略和长期行情可用性验证。

欢迎通过 Issues 报告可复现问题，或提交聚焦单一问题的 Pull Request。请使用合成数据复现，避免上传真实账本、备份密码、签名文件或带个人资产的截图。

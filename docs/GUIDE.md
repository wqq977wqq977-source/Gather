# Gather 使用指南

[返回 README](../README.md)

本指南对应 Gather 0.7.0。Gather 用于汇总需要关注的账户余额与持仓；界面目前为中文。

## 录入与日常维护

### 账户和现金

在「账户」添加银行、证券、数字资产或其他资金账户，选择名称与图标，手动填写人民币现金余额。

证券账户的余额栏只填**可用现金**，持仓另行录入。例如券商显示总资产 15,000 元，其中可用现金 10,000 元、持仓市值 5,000 元，应将 10,000 元填为现金，另加持仓。把 15,000 元填为现金会使持仓被重复计入。

「资金划转」只在两个账户的现金间转移金额，不改变总资产；手续费需另行调整余额。

### 持仓

股票／ETF 归属于证券账户，数字货币归属于数字资产账户。录入代码或选择币种，再填写数量和**单位成本**：

| 字段 | 口径 |
| --- | --- |
| 股票／ETF 数量 | 股／份，整数 |
| 数字货币数量 | 币，最多 8 位小数 |
| 单位成本 | 人民币元，最多 6 位小数 |
| 持仓市值 | 数量 × 有效报价；无报价时以成本估值 |

新增持仓不会扣减现金。买卖后需要自行核对数量、成本与可用现金；应用不连接银行、券商或钱包，不自动同步成交，也不执行交易。手续费、分红、拆并股和已实现收益需自行维护。

支持的数字货币为 BTC、ETH、SOL、BNB、XRP、DOGE、USDT、USDC。稳定币也作为持仓录入，不直接视为人民币现金。数字资产账户中的人民币现金归入「其他资金」。

### 示例预览

首次打开点「先看看示例」，或进入「设置与数据 → 预览示例」。

示例账本提供 90 天合成历史，与本人账本隔离；页面持续显示「示例预览 · 不计入你的资产」。示例行情为静态展示，不代表当前报价。退出示例后返回自己的账本。

## 图表与显示

### 总览与统计

总览汇总账户现金和持仓市值。统计提供近 7 天、近 30 天和全部已有记录的趋势、期间资产变化、最高／最低以及当前分布。

每日快照按**北京时间**保存，同一天保留最新估值，从首次记录开始积累；没有记录的日期不会补造。后台任务由 Android 择机执行，不能保证每天固定时间记录。只有一条记录时不计算增长。

### 多层桑基图

入口：「统计 → 桑基图」。

- **按类别：** 总资产 → 类别 → 账户 → 现金／持仓。
- **按账户：** 总资产 → 账户 → 现金／持仓。
- 默认展示全部非零分支；点节点选择和高亮归属路径，图下显示完整名称、精确金额与占总资产比例。
- 点「放大细看」后可横向平移，节点较多时可纵向滚动；点「适合屏幕」恢复。
- 同一账户可能出现在不同类别下，每处只计入该类别资产，各列总额保持一致。

分类包括银行存款、证券持仓、证券现金、其他资金和数字货币。图表示**当前构成**，不表示历史现金流。隐藏金额时，整张资产图形、金额和比例同步隐藏。

README 的配图为合成数据功能示意，不是实机截图。示例证券账户在两条类别分支下分别显示持仓 35,000 元与可用现金 10,000 元，账户合计 45,000 元。

### 风格与币种

「设置与数据 → 界面风格」提供彩铅手帐与蓝墨手帐。两种风格共享布局与离线字体，跟随系统深浅色；当前共用一套深色配色。

「设置与数据 → 显示币种」提供 CNY / USD。美元显示需要有效的“1 美元对应多少人民币”汇率，可获取带日期的 Frankfurter 参考汇率，也可手动填写。

**账本、录入和历史流水始终是 CNY。** USD 只改变显示；历史美元曲线同样按当前选定参考汇率换算，不代表各历史日期的美元估值。界面风格、显示币种及参考汇率偏好不包含在账本备份内。

## 计算口径与行情

### 几个金额的区别

| 读数 | 含义 |
| --- | --- |
| 总资产 | 全部账户现金 + 持仓市值 |
| 持仓浮盈 | 当前持仓市值 − 录入成本 |
| 每日／期间资产变化 | 两次已有记录的总资产差额，包含资金流入流出、余额调整、数量调整与行情变化 |
| 行情变动 | 股票以昨收为基准，数字货币以 24 小时变化为基准；混合周期的合计只供观察 |

**资产变化与行情变动均不等于投资收益。** 当前工具没有自动还原完整交易、费用、分红与已实现收益，不能把资产增长曲线直接当作策略收益率曲线。

### 行情与网络

| 用途 | 服务 | 数据口径 |
| --- | --- | --- |
| A 股／场内 ETF | 腾讯行情 | 股票快照、较昨收变化 |
| 数字货币 | CoinGecko | 人民币快照、24 小时变化 |
| 美元显示折算 | Frankfurter | 带日期的 USD / CNY 参考汇率 |

公共行情可能延迟、限流或不可用。打开应用时检查行情，前台每 60 秒检查一次；后台任务受 Android 系统调度和厂商策略影响，不保证准点。

每笔持仓展示报价时间。断网或更新失败时保留上次有效报价；无有效报价时暂按成本估值。查看每日记录可以核对记录时间与行情信息。

## 隐私与备份

### 本机数据

账本保存在应用私有目录，禁用系统自动云备份，无登录或云端账本服务。**本机账本未额外加密，也没有应用锁。** 金额隐藏只影响界面展示，不能替代本机加密或设备锁屏。

外部请求用于行情和参考汇率，不上传账户名称、余额或持仓数量；服务提供方仍可看到网络请求以及查询的证券／币种。

### 导出与恢复

1. 在「设置与数据 → 导出加密备份」设置至少 8 位密码。
2. 选择自己保管的位置，保存 `.guilong` 文件，并妥善保管密码。
3. 恢复时进入「设置与数据 → 从备份恢复」，选择文件、输入密码并检查账户与持仓数量。
4. 确认后替换当前账本。操作前建议先导出当前账本。

备份使用密码派生密钥和 AES-GCM 加密。`.guilong` 扩展名为兼容旧备份而保留，产品名已更改为 Gather。

当前账本 schema 3 可读取旧 schema 1 / 2；旧版应用不能读取新 schema。每日快照包含在备份内，界面风格和显示币种等偏好不包含在内。

**忘记密码无法恢复。卸载或清除应用数据会删除本机账本。** 导出成功后请保留可访问的备份副本。

## 常见问题

### 为什么资产变多了，不能直接说赚了钱？

转入资金、增加账户或调整持仓数量都会改变总资产。当前曲线展示资产规模变化，未剔除这些因素，因此不能直接作为投资收益。

### 为什么今天显示“较上次记录”？

若前一条记录并非昨天，应用会比较最近两条已有记录，不补造缺失日期，也不把跨日差额标成单日收益。

### 为什么美元历史曲线会随参考汇率变化？

历史记录存的是人民币。切换美元后，整条曲线用当前参考汇率折算，因此参考汇率变化会改变显示值。

### 为什么安装自己构建的 APK 无法覆盖官方版本？

Android 的覆盖安装需要匹配签名。官方私有签名身份不随源码发布，其他人构建的 APK 签名不同。涉及卸载前务必导出备份；详见 [构建说明](BUILD.md)。

### 如何报告问题？

在 [Issues](https://github.com/wqq977wqq977-source/Gather/issues) 写明应用版本、Android 版本、操作步骤、预期与实际行为。优先使用示例账本或合成数据复现，请勿附上真实账本、备份密码、私有签名或带个人资产的截图。

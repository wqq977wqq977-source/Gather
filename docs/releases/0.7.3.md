# Gather 0.7.3

2026-11-02，versionCode 11。基于 v0.7.2 的行情来源归因修正。

## 更新

- 来源不完整的旧每日记录中，新观察到的行情变化单独显示为「行情 / 估值」，不再全部归为「未分类变化」。
- 无法追溯的导入差额仍保留为未分类；不推算或补造旧历史。
- 同日行情变化累计保存，重复报价／重载不重复累计，手动持仓调整单独归类；次日重新累计。
- 备份 schema 升为 5，保存已观察行情变化，兼容读取 schema 1–4。
- 保留 0.7.2 的手动收入、每日变化来源、原子存储及失败回滚保护。

## 验证与发布

- 本机合成文件系统检查：122 条账本断言和 230 条收入／来源断言通过，包含旧 schema、旧记录行情归因、重复报价、混合调整、备份往返、失败写入回滚和次日累计。
- 本机离线签名 release 构建、Android 15 模拟器覆盖安装与冷启动通过；本次修改的 Python 构建器通过 Ruff。
- 正式发行使用 GitHub 受保护的原签名身份。工作流先运行 Gradle debug 构建与全部领域／存储检查，再构建签名 release，并与公开 v0.7.1 APK 的原签名证书比对；校验通过后才发布。
- GitHub 发行 APK 由 Gradle 构建，本机离线构建的模拟器检查不能代替完整真机 UI 回归。

请先在旧版导出加密备份，再覆盖安装，不要先卸载。旧版应用不支持新 schema 的备份。未进行完整真机 UI、TalkBack 或长期行情／后台回归。

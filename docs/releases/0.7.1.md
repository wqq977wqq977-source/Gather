# Gather 0.7.1

2026-10-30，versionCode 9。

## 更新

- 加密备份的文件读取、加解密、导出和恢复改为后台执行，显示处理状态；进程存活期间结果可跨页面重建保留。
- 修复备份期间页面重建与后台恢复同时读取／写入账本的竞争，并避免导出后立即重绘等待后台账本锁。
- 恢复前保留明确确认，拒绝并发备份操作；临时导出文件只存加密内容，导出完成或取消后清理。
- 恢复时丢弃旧行情请求的成功结果，避免旧请求覆盖刚恢复的报价。
- 行情自动刷新时保留桑基图选中路径、放大状态与滚动位置。
- 新增 Gradle 领域检查任务和 GitHub Actions debug 构建／领域检查；桑基图离线测试支持指定 JRE。
- 沿用原包名、签名和 `.guilong` 备份格式，可覆盖同签名旧版本。

## 审查

代码质量与产品要求两路审查均发现同一项后台恢复／页面重建竞争；已通过集中延后备份期间的绘制修复，并复查通过。字符串结果类型可后续改为枚举，属于非阻塞维护建议。

# Gather 0.9.0

2026-11-03，versionCode 14。包含本地 0.8 系列开发与 0.9 界面精简，基于已发布的 0.7.3 更新。

## 更新

- 新增资产日历，按月查看已有每日快照、金额／涨跌幅、记录间隔及月度汇总；缺失记录不补造。
- 底部导航改为日历、总览、统计、持仓；账户、记收入和划转入口保留在总览。导航顺序和页面图标可自定义并重启保留。
- 设置改为独立页面，保留显示与外观、数据与备份、帮助入口，支持更多账户图标。
- 统计分布支持类别／账户／持仓切换，按金额排序，展示最大占比及现金占比。
- 界面减少重复说明与操作，持仓页顶部统一显示报价时间；涨为绿色、跌为红色，零变化为中性色。
- 人民币／美元直接切换。美元使用每日参考汇率并定期尝试更新；已有缓存时沿用缓存，无缓存获取失败时回退人民币。
- 关于页面新增手动检查稳定版更新，打开 GitHub 发布页；不自动下载或安装。
- 保留原签名、包名、schema 5 账本与加密备份兼容性。导航及显示偏好不纳入账本备份。

## 本次验证与边界

- 本次重新运行：99 条资产、27 条日历、25 条导航 JVM 断言通过。
- 当前源码的独立 Android 测试包：24 条界面精简断言通过，覆盖页面、分布模式、日历、币种选择及版本比较。
- Python 构建／测试脚本通过 Ruff 检查与格式检查，Git 空白检查通过。
- 正式发布工作流执行 Gradle debug 构建和完整领域／存储检查，再构建 release，并与公开旧版的原签名证书比对；通过后才发布。
- GitHub 正式 APK 发布后回下载，校验摘要、版本及源码提交，并在项目专用 Android 15 模拟器覆盖安装、冷启动。

此前开发记录验证了每日参考汇率切换及更新检查失败提示；不把单次联网结果视为长期可用性保证。尚未完成应用内在线更新检查成功路径、完整真实手机、TalkBack 或长期后台验证。更新前请导出加密备份，直接覆盖安装，不要先卸载。

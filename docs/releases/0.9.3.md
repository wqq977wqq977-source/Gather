# Gather 0.9.3

2026-11-04，versionCode 17。小版本更新。

- 离线资产记录与联网行情更新拆为两个约每小时执行的后台任务；无网络时仍可记录最近已知估值。
- 任务持久保存，升级后首次打开完成注册，设备重启后由 Android 恢复；重复打开不会反复推迟已安排的任务。
- 移除统计页重复的「每日变化／查看日历」入口，日历仍可从底部导航进入。
- 沿用原签名、包名、账本和备份格式，可覆盖安装。

本次按轻量档位发布，仅进行构建、版本／APK 结构、原签名兼容、文件校验与正式包的模拟器覆盖安装、冷启动检查，不执行完整领域或界面回归。

后台任务受 Android 省电、厂商策略、关机及强行停止影响，不保证准点，也不补造缺失日期；强行停止后需重新打开应用。长期后台表现及真实设备重启恢复未在本次轻量检查中验证。

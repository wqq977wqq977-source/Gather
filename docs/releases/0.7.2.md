# Gather 0.7.2

2026-11-02，versionCode 10。对 v0.7.1 的增量功能更新。

## 更新
- 在「账户 → 添加资产」选择「记一笔收入」，支持选择到账账户、工资／奖金／其他收入，填写人民币金额和备注；账户与账户详情有快捷入口。
- 收入单次原子增加账户现金，并保存到变更记录和按北京时间记录的当日资产快照。刷新行情不会重复入账。
- 总览、统计和每日记录的资产变化下方，用小字展示「收入」「余额调整」「持仓调整」「行情 / 估值」等来源。金额隐藏时不显示来源金额。
- 每日来源汇总随快照备份。schema 4 可读取既有 v1／v2／v3 账本。来源不全的旧记录标为「未分类变化」，不捏造历史归因。
- 修正 USD 大额金额显示的中间换算溢出边界。

## 验证与限制
- Android CI 对上一轮代码通过了 debug 构建、领域检查，以及新增的 194 项收入／来源存储断言和原有测试。
- 发布流程需使用私有原签名身份，并自动与公开 v0.7.1 APK 的签名证书比对。签名不一致、构建失败或原版校验失败时不得发布新 APK。
- 未进行完整真机 UI 回归。行情刷新由外部接口和系统调度决定。
- 建议升级前通过「设置与数据 → 导出加密备份」备份账本。不得先卸载旧版。

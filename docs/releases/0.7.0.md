# Gather 0.7.0

2026-10-28，versionCode 8。

## 更新

- 同屏多层桑基图：按类别显示总资产 → 类别 → 账户 → 现金／持仓四列，按账户显示三列；默认展示全部非零分支。
- 支持放大、横向平移和纵向滚动；点击节点选择、高亮归属路径，并在图下读取精确金额与占比。
- 金额隐藏时隐藏整张资产图形及比例。
- 修正窗口重新获得焦点后系统状态栏和导航栏的深浅色外观。
- 沿用原包名、签名和备份格式，可覆盖同签名旧版本。

- 离线 release 构建及 APK v2/v3 签名验证通过；与 v0.6.1 的签名证书一致。

- 99 条 v6、62 条桑基图、29 条账本 JVM 断言通过；13 组行情解析／加密备份检查通过。
